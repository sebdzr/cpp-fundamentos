# Laboratorio 03 — Listas enlazadas y templates

Este laboratorio conecta el manejo de nodos con la reutilización de código para distintos tipos de datos.

- [Parte 1: lista simple genérica](parte_1_listas/README.md).
- [Parte 2: inversión de arreglos](parte_2_templates/README.md).

Los informes locales contienen ejercicios y pruebas adicionales. La segunda parte del código conservado corresponde a la inversión: no incluye las funciones de mínimo, ordenamiento y búsqueda que aparecen en el informe. Queda pendiente recuperar sus fuentes originales si se quieren incorporar.

Los PDF originales permanecen en la carpeta local `docs/` y se excluyen de Git porque contienen identificadores estudiantiles. Las instrucciones necesarias para compilar están en estos README.
